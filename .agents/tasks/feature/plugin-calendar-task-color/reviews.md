# Результаты ревью ветки `feature/plugin-calendar-task-color`

## 1. Security Review (Субагент `f01b91be-e78d-4d54-8a68-7eb7e3e71e1f`)

### Сводка
- 🔴 **High (1):** Неограниченный запрос `limit: -1` без фильтра по датам (риск переполнения памяти сервера Node.js и зависания вкладки браузера при 50k+ записей).
- 🟡 **Medium (3):** 
  - Падение Vue-компонента при нестроковых значениях (`item.Color`, `item.Start` как числа/объекты вызывают `TypeError: .slice/.startsWith is not a function`).
  - Ошибка цепочки поставок в `package.json`: некорректная версия `"typescript": "^7.0.2"` (TS сейчас 5.x).
  - Навигация через `window.location.href` сбрасывает SPA-состояние Directus и не экранирует параметры URI.
- 🟢 **Low (2):** 
  - Короткие 3-значные hex-цвета (`#fff`) ломают расчет яркости YIQ и дают невидимый белый текст на белом фоне.
  - Мутация объекта `Date` in-place в расчете шапки недели при переходе через границу месяца.
- ℹ️ **Info (2):** 
  - Жестко закодированные имена полей без опций в `defineLayout`.
  - XSS-безопасность проверена: интерполяция шаблона Vue и DOM `title`/`style` безопасны.

## 2. Ponytail Review (Clean Code & Architecture, Субагент `d7dc10dc-1c85-4fdb-91f6-0b2702b31095`)

### Must Fix
1. **Повреждение интервала недели через границу месяца** (`src/layout.vue:175-178`): `curr.setDate(first)` изменяет дату in-place, ломая вторую границу недели.
2. **Застревание навигации по месяцам 29-31 числа** (`src/layout.vue:186, 196`): вызов `d.setMonth(d.getMonth() - 1)` на 31-м числе перескакивает через короткие месяцы (февраль/апрель). Требуется фиксация `d.setDate(1)`.
3. **Невидимый текст при 3-значных hex-цветах** (`src/layout.vue:294-303`): `#fff` считается темным фоном (YIQ=85) и красит текст в белый. Требуется раскрытие до 6 символов.
4. **Сдвиг дней из-за UTC-среза строки** (`src/layout.vue:285, 318`): `item.Start.slice(0, 10)` берет дату в UTC, а ячейки календаря отображают локальное время браузера. Вечерние/утренние задачи сдвигаются на соседний день.
5. **Загрузка всей таблицы базы данных** (`src/layout.vue:147-152`): `limit: -1` без фильтра диапазона дат.

### Should Fix
6. Жесткая перезагрузка страницы в `openItem` вместо `router.push`.
7. Исчезновение многодневных задач после первого дня (проверка только `Start`, игнорирование `End`).
8. Жестко зашитые поля (`'Start'`, `'Title'`, `'Color'`) без опций настройки раскладки.
9. Квадратичный цикл $O(\text{ячейки} \times N)$ в `calendarCells` (оптимизация через `Map<dateKey, TaskItem[]>`).
10. Отсутствие unit-тестов на логику дат и контраста (рекомендован минимальный `vitest`).

- `Verdict: fix 1, 2, 3, 4, 5 first.`
